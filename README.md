# Пони-рулетка

Маленькая игра на **Godot 4.5** в жанре «рулетки с заряженной пушкой» в пастельном пони-стиле.
Ты — пегаска Звёздочка, против тебя — хитрая единорожка Карамелька (ИИ).

## Правила
- В Кексовую пушку заряжают **острые перчики** (−1 сердечко) и **кексы-конфетти** (холостые).
  Сколько каких — показывают, порядок — секрет.
- Кекс в себя — ходишь ещё раз; любой другой исход передаёт ход.
- Предметы: Кристалл (подсмотреть заряд), Яблочко (+1 ❤), Радужная пыль (перчик ×2),
  Ленточка (соперница пропускает ход), Коктейль (выбросить текущий заряд).
- 3 раунда (2 → 4 → 6 сердечек), побеждает выигравшая 2 раунда.

## Запуск
Открыть папку в Godot 4.5 → **F5**. Вся графика и звуки генерируются кодом — ассетов нет.

```bash
godot --path .                       # играть
godot --path . -- --demo             # ИИ играет сам с собой (смотреть матч)
godot --headless --path . --import   # один раз, чтобы собрать кэш классов
godot --headless --path . -s tests/test_logic.gd   # тесты логики + 500 матчей ИИ vs ИИ
```

## Структура
| Файл | Что делает |
|---|---|
| `scripts/game_logic.gd` | чистая логика (заряды, выстрелы, предметы, раунды), детерминирована по seed |
| `scripts/ai.gd` | решения ИИ по вероятности перчика и предметам |
| `scripts/main.gd` | UI, анимации, очерёдность ходов |
| `scripts/pony.gd`, `cannon.gd`, `background.gd`, `icons.gd` | отрисовка кодом |
| `scripts/sfx.gd` | синтез звуков |
| `tests/test_logic.gd` | headless-тесты |
